📦 What is dplyr?

R-এর সবচেয়ে জনপ্রিয় data manipulation package

📖 Definition

`dplyr` হলো R-এর একটি জনপ্রিয় data manipulation package, যা dataset পরিষ্কার, filter, sort, transform, summarize এবং combine করার জন্য ব্যবহৃত হয়।

R
install.packages("dplyr")

⚙️ Loading the Package

Use `library(dplyr)` to load the package before using any of its functions.

R
library(dplyr)

🧩 Core dplyr Verbs

The five most important functions you need to know

select()
Select specific columns
select(df, name, age)
filter()
Filter rows by conditions
filter(df, age > 25)
arrange()
Sort rows by column values
arrange(df, age)
mutate()
Create or modify columns
mutate(df, bonus = salary * 0.1)
summarise()
Aggregate data into summaries
summarise(df, avg = mean(x))
group_by()
Group data by categories
group_by(df, dept)
count()
Count observations per group
count(df, dept)
distinct()
Remove duplicate rows
distinct(df, city)
slice()
Select rows by position
slice(df, 1:5)
rename()
Rename columns
rename(df, name = full_name)

🔗 Pipe Operator

Chain multiple operations together for readable code

Pipe operator ব্যবহার করে এক function-এর output পরবর্তী function-এ পাঠানো যায়।

Data
↓
filter()
↓
select()
↓
mutate()
↓
summarise()
R — Without Pipe
filter(df, age > 25)
R — With Pipe (|>)
df |> filter(age > 25)
💡 Modern R recommends the native pipe |> (R 4.1+). The magrittr pipe %>% is still widely used and works the same way.

🔗 Joins

Combine two datasets based on matching keys

R — left_join example
employees |> left_join( departments, by = "department_id" )
R — Different key names
left_join( x, y, by = c("id" = "employee_id") )
Join Result
inner_joinMatching rows only
left_joinAll rows from left
right_joinAll rows from right
full_joinAll rows from both
semi_joinLeft rows with matches
anti_joinLeft rows without matches

🚀 Complete Real-World Workflow

A practical example using multiple dplyr verbs together

R — Sales Analysis Pipeline
sales |> filter( city == "Dhaka", sales > 5000 ) |> mutate( profit = sales * 0.15 ) |> group_by(category) |> summarise( total_sales = sum(sales, na.rm = TRUE), avg_sales = mean(sales, na.rm = TRUE), total_profit = sum(profit, na.rm = TRUE) ) |> arrange(desc(total_sales))
📋 Step-by-step: 1. Filter Dhaka → 2. Keep sales > 5000 → 3. Calculate profit → 4. Group by category → 5. Calculate summary → 6. Sort highest sales first
